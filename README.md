# BenchOS

A tiny operating system that runs in your web browser, built with plain HTML, CSS and JavaScript. It has a circuit board theme inspired by my hardware and electronics projects.

## Demo

**Try it here:** https://YOUR-LINK-HERE

No login or password needed. Anyone can open it and test it.

![BenchOS screenshot](screenshot.png)

## Features

- **Draggable windows:** move windows by their title bar, resize them from the corner, and minimize, maximize or close them
- **Taskbar:** shows your open windows and a live clock, with a Bench menu to launch apps
- **Desktop icons:** click any icon to open an app
- **Welcome window:** a short intro about me

## Apps

- **Projects:** a list of things I have built, like RAPTOR, TTOR, JARVIS and my hackpad
- **Notes:** a notepad that saves automatically in your browser
- **Terminal:** type commands like `help`, `ls`, `open notes`, `projects`, `theme midnight` and `ohm 5 220`
- **Resistor Lab:** pick four color bands and see the resistor value
- **Settings:** change the accent color and board color, or reset everything

## What I added myself

These features were not in the workshop guide:

- Resistor Lab (resistor color code decoder)
- A working terminal with its own commands, including an Ohm's law calculator
- Theme settings that are remembered between visits
- Custom circuit board design
